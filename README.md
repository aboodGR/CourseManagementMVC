Course Management MVC

Small ASP.NET Core MVC project I made to practice MVC, Entity Framework Core, SQL Server, and CRUD operations.


Features

- View courses
- Add new courses
- Edit courses
- Delete courses
- View course details

Technologies

- C#
- ASP.NET Core MVC
- Entity Framework Core
- SQL Server
- Razor Views

What I practiced

This project helped me understand how the controller, views, models, EF Core, and SQL Server work together in an MVC application.
